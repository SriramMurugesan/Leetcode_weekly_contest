## Format Guidelines

Each contest problem follows standard LeetCode formatting:
- **Problem Metadata**: Contest number, problem title, LeetCode link, difficulty, and problem description.
- **Typing & Signatures**: Type annotations matching official LeetCode method signatures.
- **Self-contained Verification**: `if __name__ == "__main__":` test harness with example test cases and assertions for instant local execution.
